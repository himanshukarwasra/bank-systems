# Banking System - Mini Project

A beginner-friendly Python mini project that simulates basic banking operations.

## Features added in project

- Create a bank account
- Generate a unique account number
- Login using account number and PIN
- Check account balance
- Deposit money
- Withdraw money
- Transfer money between accounts
- View transaction history
- Change PIN
- Logout
- Save account data between program runs

## Python Concepts Used

- Variables and data types
- Conditional statements
- Loops
- Functions
- Lists and dictionaries
- String operations
- Modules
- File handling
- JSON data storage

## Python Modules

The project uses:

- `random` for generating account numbers
- `datetime` for transaction date and time
- `json` for saving account data
- `pathlib` for handling the data file

## Requirements

Python 3.8 or newer is recommended.

No external packages are required.

## How to Run

1. Install Python.
2. Open a terminal in this project folder.
3. Run:

```bash
python main.py
```

On some systems you may need:

```bash
python3 main.py
```

## First Use

Choose:

```text
1. Create Account
```

Enter your name, phone number and a 4-digit PIN.

The program will generate an account number. Save it because it is required for login.

## Important Note

PINs are stored locally in a JSON file for simplicity.
